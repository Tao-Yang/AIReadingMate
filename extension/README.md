# 阅读伴侣 · Edge 扩展

点击工具栏的小机器人图标，机器人就出现在当前页面右下角，对浏览器中打开的英文 PDF 划词即得中文注释。注释来自已部署的后端 `https://ai-reading-mate.onrender.com`（离线 ECDICT 词库 + 明清历史文化词库，未命中再走大模型）。

## 安装（加载未打包扩展）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车。
2. 打开右下角（或左侧）的「开发人员模式 / Developer mode」。
3. 点击「加载解压缩的扩展 / Load unpacked」。
4. 选择本文件夹 `extension`（包含 `manifest.json` 的目录）。
5. 工具栏出现琥珀色机器人图标，点它即可唤出/收起机器人。

## 使用

1. 在 Edge 中打开任意英文 PDF（或英文网页）。
2. 点击工具栏机器人图标，右下角出现伴读机器人。
3. 取词两种方式：
   - **划词**：在页面上直接选中英文，机器人自动给出注释（适用于网页与 PDF.js 类阅读器）。
   - **复制/粘贴**：在 Edge 内置 PDF 查看器里选中英文按 `Ctrl+C`，再点浮层里的「读取剪贴板」或把文本粘到输入框后点「注释」。
4. 注释显示在机器人下方的气泡里。

## 关于 Edge 内置 PDF 查看器的限制

Edge 内置 PDF 查看器（PDFium）**不会把用户在 PDF 里的文字选择暴露给扩展**，因此无法像网页那样自动取词。扩展为此提供了「复制后一键注释 / 剪贴板读取」的兜底路径。

如果希望在 PDF 上也能**划词即注、零手动复制**，需要让扩展用自带的 PDF.js 阅读器接管 PDF 页面（改造量较大）。需要的话告诉我，我可以在此基础上加上这个模式。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单：图标点击、权限、后端主机权限 |
| `background.js` | 点击图标切换浮层；代理注释请求（避开内容脚本 CORS） |
| `content.js` | 注入右下角机器人浮层，捕获划词/粘贴文本并展示注释 |
| `robot.js` | Three.js 琥珀身小机器人形象与动画 |
| `vendor/three.min.js` | 本地 Three.js r128（不依赖 CDN） |
| `overlay.css` | 浮层样式（注入 Shadow DOM，不污染宿主页面） |
| `icons/` | 工具栏图标 |

## 隐私

扩展只把你**当前选中/粘贴**的英文片段发送到上述后端换取中文注释，不采集页面其它内容。
