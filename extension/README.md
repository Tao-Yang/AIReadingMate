# 阅读伴侣 · Edge 扩展

点击工具栏的小机器人图标，机器人就出现在当前页面右下角，对浏览器中打开的英文 PDF 划词即得中文注释。注释来自已部署的后端 `https://ai-reading-mate.onrender.com`（离线 ECDICT 词库 + 明清历史文化词库，未命中再走大模型）。

## 安装（加载未打包扩展）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车。
2. 打开右下角（或左侧）的「开发人员模式 / Developer mode」。
3. 点击「加载解压缩的扩展 / Load unpacked」。
4. 选择本文件夹 `extension`（包含 `manifest.json` 的目录）。
5. **打开本扩展详情里的「允许访问文件 URL / Allow access to file URLs」开关**——本地 PDF（`file:///...`）的接管与读取都依赖它。
6. 工具栏出现琥珀色机器人图标，点它即可唤出/收起机器人。

## 使用

1. 在 Edge 中打开任意英文 PDF（本地 `file:///` 或在线 `https://...pdf`）。扩展会**自动用自带的 PDF.js 查看器接管**该 PDF。
2. 取词三种方式：
   - **点词**：用鼠标**单击**一个英文单词，右下角机器人立即弹出中文注释。
   - **划词**：拖蓝选中一段英文，自动给出注释。
   - **复制/粘贴**：仍保留手动输入框作为兜底。
3. 注释显示在机器人下方的气泡里。

## 关于 PDF 取词

Edge **内置** PDF 查看器（PDFium）不会把文字选择暴露给扩展，无法点词/划词。为此扩展**自带 PDF.js 查看器**：检测到 `.pdf` 跳转时（本地或在线）自动重定向到自带查看器，把文字渲染成真实、透明可选中的 DOM 文本层，从而支持点词与划词即注。

- 本地 PDF 需在 `edge://extensions` 打开本扩展的「允许访问文件 URL」开关。
- 若加载本地 PDF 报错，多半就是该开关未打开。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单：图标点击、权限、后端主机权限 |
| `background.js` | 点击图标切换浮层；代理注释请求（避开内容脚本 CORS） |
| `content.js` | 注入右下角机器人浮层，捕获点词/划词/粘贴文本并展示注释 |
| `robot.js` | Three.js 琢珀身小机器人形象与动画 |
| `vendor/three.min.js` | 本地 Three.js r128（不依赖 CDN） |
| `vendor/pdfjs/` | 自带 PDF.js 库与自定义查看器（`viewer.html/js/css` + `pdf.min.js` + `pdf.worker.min.js`） |
| `overlay.css` | 浮层样式（注入 Shadow DOM，不污染宿主页面） |
| `icons/` | 工具栏图标 |

## 隐私

扩展只把你**当前选中/粘贴**的英文片段发送到上述后端换取中文注释，不采集页面其它内容。
